# CampusGuide <!-- 中文名待定 -->

> 杭州电子科技大学第二届 AIGC 应用创新大赛参赛作品及生成式人工智能应用基础期末作业

一个**校园事务 AI 指导**：用户说出想办的事，它返回一张可执行的"行动卡"——去哪办、带什么、多久办完、依据是什么等。

现有校园入口（如各类助手站）解决的是"入口在哪儿"，前提是用户已经知道要找什么。本项目解决的是**用户不知道该找什么**的那一步。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/
```

不配置任何密钥也能完整运行：后端会退化为本地知识库检索，界面行为一致。
需要接入大模型时，复制 `.env.example` 为 `.env` 并填写 `LLM_API_KEY`（任意 OpenAI 兼容接口）。

## 设计要点

- **行动卡而不是搜索结果**：输出是结构化对象（步骤 / 材料 / 入口 / 时限 / 依据），可以照着做完，并能一键加入待办。
- **入口可用性是一等公民**：卡片标注需登录、需微信、需杭电钉，并区分学校系统与第三方。实测 114 个官方入口里，能打开即用的几乎没有。
- **每条结论都有依据**：卡片底部固定展示来源，未与官方核对的条目显示「待核验」。
- **只指路不代劳**：不登录任何校内系统，不代替用户提交；需要提交时只生成可复制的草稿。
- **两级降级**：模型可用时走语义检索；接口不可用、超时或无密钥时自动退回本地关键词检索，答辩现场断网仍可演示。
- **可迁移**：办事条目是纯数据，换学校只替换 `knowledge.ts` 里的条目与链接。
