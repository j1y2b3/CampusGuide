# 项目方案 PPT 大纲（≤ 20 页）

> 提交材料三：PPT，评分占比 37.5%（预赛最高项）。
> 要求涵盖：创作理念、问题与需求分析、技术路径或工作流、设计过程、最终成果与团队协作。
> 建议页数与内容如下，可按实际裁减。

## 第 1 页 · 封面

- 标题：校园事务助手 / CampusGuide
- 副标题：说出你要办的事
- 参赛信息、团队名称、成员

## 第 2 页 · 一句话讲清是什么

> 学校有 114 个办事入口，但学生仍然不知道怎么用。
> 我们做的不是第 115 个入口，而是**告诉你该去哪个、以及为什么进不去**的那一层。

## 第 3 页 · 问题从哪来（用真实经历开场）

- 场景：想约个羽毛球场地，搜到入口，点进去没反应
- 场景：想查寝室电费，找到网页，进去要登录，登录完找不到入口
- 一句话：**"知道叫什么"和"能办成"之间，隔着好几层。**

## 第 4 页 · 调研数据（本页是论证核心）

对校务服务网 114 项服务逐项实测跳转地址：

| 分类 | 数量 |
|---|---|
| 只能在钉钉内打开的深链 | 18 |
| 由第三方（杭电助手）提供 | 19 |
| 第三方后勤/图书馆页面 | ~30 |
| 学校自有系统（全需登录） | 其余 |

大字结论：**能在浏览器打开即用的，几乎没有。**

## 第 5 页 · 我们自己的知识库也证明了这一点

24 件事的真实分布：

- 直接可用 **5**
- 需登录 **12**
- 只能在微信 / 杭电钉 **7**

配图：入口总览页截图（分组 + 数字卡片）

## 第 6 页 · 三个实测案例

| 场景 | 现象 | 证据 |
|---|---|---|
| 场馆速约 | 浏览器打不开 | 统一身份认证入口返回 **502** |
| 第二课堂 | 只能微信进 | 走微信静默授权 |
| 阳光乐跑 | 首次必须先网页改密码 | 否则小程序登不进去 |

## 第 7 页 · 目标用户

- 新生：完全不知道去哪
- 老生：知道大概，但不确定要不要登录 / 手机能不能开
- 一句话：所有人都在"入口"和"办成"之间浪费过一次时间

## 第 8 页 · 解决方案：行动卡

一张卡说清五件事：**入口 / 打开方式 / 步骤 / 材料 / 时限 + 依据**

配图：真实卡片截图（建议用图书馆或场馆速约）

## 第 9 页 · 核心差异：打开方式

- 直接可用
- 需登录
- 只能在微信 / 杭电钉

> 我们不给点了没反应的链接，我们告诉你**该在哪个 App 里打开**。

配图：入口总览页分组

## 第 10 页 · 另一个差异：参数化深链

用户："我想借《平凡的世界》"
系统直接生成：`opac.hdu.edu.cn/...strText=平凡的世界`

对比：杭电助手 AI 对同一问题回答"无法确认……参考链接：暂无"

## 第 11 页 · 还有一层：办完要记着

- 行动卡 → 加入我的待办 → 截止倒计时
- 解决"没有人替你记着"

## 第 12 页 · 技术架构

```
输入 → 意图识别
        ├─ 模型：在知识库 id 白名单内选择（防编造）
        └─ 本地：触发词 + 二元组打分（断网可用）
     → 结构化行动卡 JSON → 前端渲染
```

强调：Key 只在服务端；模型不可用自动降级。

## 第 13 页 · 知识库设计（可迁移性）

- 一条数据 = 一件事，字段见文档
- 换学校 = 换一份数据 + 一组 URL，代码零改动
- 现场可演示：切到"只有 3 条数据的 XX 学院"照样出卡

## 第 14 页 · AI 在哪些环节参与

| 环节 | AI 做什么 |
|---|---|
| 需求分析 | 对比三种产品形态的优劣，收敛方案 |
| 知识整理 | 从通知、告示、系统前端文案中抽取规则 |
| 代码生成 | 组件、检索算法、接口 |
| 文案 | 卡片措辞、兜底话术 |
| 核查 | **人工完成**，未核实一律标注 |

## 第 15 页 · 开发过程与迭代

- v1：问事 → 行动卡 → 待办
- v2：删除冗余区块，聚焦单一路径
- v3：知识库扩容 + 入口可用性建模
- v4：入口总览页
- 一次方向性回退：作业模块开发后按小组决策撤下（记录在 git 历史）

## 第 16 页 · 测试与验证

| 用例 | 结果 |
|---|---|
| 寝室没水了怎么办 | 命中订水 / 报修，标注需微信 |
| 体育馆怎么约 | 命中场馆速约，标注需钉钉 |
| 我想借《平凡的世界》 | 生成已填书名的检索深链 |
| 断网 / 无 Key | 降级本地检索，仍出卡 |
| 库外问题（如"我想申请奖学金"） | 明确说明未收录，不编造 |

## 第 17 页 · 诚实说明边界

- 不代登录、不代提交
- 未核实条目显示「待核验」
- 只给路径，不承诺一键直达

> 这一页是加分项，不是减分项——评委问"信息错了怎么办"，答案是这一页。
