## 三、怎么运行和演示（录制视频前必看）

### 3.1 本地运行

```powershell
cd D:\Projects\CampusGuide
npm install          # 首次需要
npm run dev          # 打开 http://localhost:5173
```

`.env` 文件**不在仓库里**（含 API Key，被 git 忽略）。没有它页面照样能跑，只是走本地关键词检索，答案措辞会简单一些，**功能演示不受影响**。

### 3.2 给组员看（同一校园网）

```powershell
npm run dev -- --host 0.0.0.0 --port 5199
```

然后把 `http://你的内网IP:5199` 发出去（用 `ipconfig` 查 IP）。若对方打不开，通常是校园网设备隔离，改用：

```powershell
npx cloudflared tunnel --url http://localhost:5199
```

⚠️ 隧道会暴露到公网，可能被他人消耗 API 额度，**看完立刻 Ctrl+C 关闭**。

### 3.3 录屏建议

- 手机尺寸视口更容易看清（浏览器 F12 → 设备模拟 → iPhone）
- 先点「入口」页展示 11 / 13 / 7 的分布，再进入「问事」
- 每张卡展开后再操作，不要快速滑过

## 四、三份材料怎么做

### 4.1 项目文档（Word）

**直接用 `docs/PROJECT-DOC.md` 转 Word 补齐。** 已有内容：

- 一、项目背景与问题（含实测数据表）
- 二、解决方案（含与杭电助手 AI 的对比表）
- 三、技术实现路径
- 五、创新点与价值
- 七、附录结构（AI 工具使用）

需要你们补的空位（文档里已用"待填"标出）：

| 位置 | 补什么 |
|---|---|
| 四、团队分工 | 成员姓名、负责模块、投入比例 |
| 七.2 工具清单 | 实际用了哪些 AI 工具（Qoder / ChatGPT / DeepSeek 等）与使用时段 |
| 七.4 人工核查情况 | 核查了哪些内容、用什么方式、结论 |

**七、附录是硬性要求**，原文写的是"项目文档最后附上 AI 工具使用、关键 Prompt、生成或开发过程、迭代优化、测试验证和人工核查情况"。直接从 `docs/ai-log/AI-LOG.md` 挑 6–8 条，按 `docs/ai-log/appendix.md` 的四段式模板（Prompt → AI 产出 → 人工修改 → 验证）整理即可。

**格式建议**：标题用 Word 内置样式（不要手动加粗当标题），正文宋体/等线小四，表格加表头底纹，页脚加页码。

### 4.2 演示视频

按 `docs/PPT-OUTLINE.md` 的时间分配录制，5 分钟版本建议：

| 时间 | 内容 | 关键动作 |
|---|---|---|
| 0:00–0:40 | 问题 | 打开校务服务网，展示 114 项列表；点一个入口，说明"打不开/要登录" |
| 0:40–1:20 | 主流程 | 问"体育馆怎么约" → 卡片显示"只能在杭电钉内打开" |
| 1:20–2:20 | 差异化 | 问"我想借《平凡的世界》"→ 点"直接打开"→ 真实检索结果页 |
| 2:20–3:10 | 论据 | 切到「入口」页，讲 11 / 13 / 7 |
| 3:10–3:50 | 闭环 | 加入待办 → 展示倒计时 |
| 3:50–4:30 | 稳健性 | 断网或误报错时的降级表现（可选但加分） |
| 4:30–5:00 | 对比与收尾 | 杭电助手 AI 对同一问题答"无法确认"的截图 vs 我们的深链 |

**压缩到 100MB 以内的方法**：

- 录制 1080p 后用剪映导出，比特率设为 **6–8 Mbps**
- 或直接录 720p
- 时长卡在 4:30 左右，留缓冲

## 五、可以说 / 不能说（重要，涉及 12.5% 诚信分）

### 5.1 有实测依据，可以放心说

| 说法 | 依据 |
|---|---|
| 校务服务网列出 114 项服务 | 实测抓取 |
| 其中 18 项只能在钉钉内打开 | 跳转地址为 `dingtalk://` 深链 |
| 19 项由杭电助手提供 | 跳转地址为 `*.hduhelp.com` |
| 我们收录 31 件事，11 件可直接用、13 件需登录、7 件只能在 App 内 | 知识库 `access` 字段统计 |
| 场馆速约的 H5 登录入口返回 502 | 实测 `/gymbook/authcertify/login?env=h5` |
| 第二课堂走微信授权，浏览器无法登录 | 实测 |
| 图书馆书目检索无需登录，可查馆藏 | 实测检索"平凡的世界"返回 22 条 |
| 杭电助手 AI 对"图书馆有没有某本书"答"无法确认……参考链接：暂无" | 实测对话记录 |

### 5.2 不要说，或要加限定

| 不要说 | 应该说 |
|---|---|
| "覆盖全校所有事务" | "收录 31 件高频事项，覆盖 10 类" |
| "一键直达所有入口" | "能在浏览器打开的给链接，其余说明该在哪个 App 打开" |
| "数据实时同步" | "信息来自公开渠道，标注了核实状态" |
| "我们的信息 100% 准确" | "已核实的条目附来源，未核实的标注「待核验」" |
| 引用杭电助手或任何第三方产品的界面截图当成自家的 | 截图可以用于对比，但必须标明来源 |

**知识库里有 13 条标记为「待核验」**（`verified: false`）。如果 PPT 或视频要展示这些条目，请照实说明"这一条还在核实"——这比假装准确更能得分。

### 5.3 绝对不要做

- 不要在任何材料里写"我们做了作业模块"——该模块已按小组决定撤下（代码在 `archive/assignment-module` 分支，未合入主线）
- 不要声称接入过学校统一身份认证或拿到过任何后台数据
- 不要把 `.env` 或任何 API Key 截图放进材料

## 六、常见问题

**Q：网页打不开/白屏？**
先 `npm install`，再确认 Node 版本 ≥ 18。

**Q：卡片显示"结果来源：本地知识库检索"？**
说明没读到 `.env` 或接口不通，功能正常，只是没用模型。对演示无影响。

**Q：想加一条办事条目？**
改 `src/data/knowledge.ts`，格式见 `docs/KNOWLEDGE-SCHEMA.md`。加完必须自测搜索能命中。

**Q：为什么有的卡片没有"直接打开"链接？**
因为那些入口需要钉钉/微信/登录，给了链接用户点了也没用。这是产品有意为之，**不是 bug**，答辩时可以主动解释这一点。

**Q：改了代码怎么提交？**
```powershell
git add -A
git commit -m "docs: 说明改了什么"
git push
```
